Wely CLI demo

Plain HTML usage

Drop the UMD bundle into any static page. Components load safely with defer and wely.ready().

How this page loads Wely

Both scripts use defer, so the bundle runs first and the boot snippet can call wely.ready() directly — no polling. 

<script src="../dist/wely.bundle.umd.js" defer></script>
<w-todo-demo title="..."></w-todo-demo>
<script defer>
  wely.ready('w-todo-demo').catch(console.error);
</script>
